# SportLog Workout Bot

Ce repository contient le travail pour le projet SportLog.

## Structure
- **/Workflow** : Le workflow n8n (format .ts) utilisable avec n8ncli.
- **/Skills** : Les skills personnalisés (Interview, Doubt Driven Dev, Hostile Review).
- **/Video** : Démo vidéo du projet.

## Utilisation
Pour importer le workflow :
1. Installer n8ncli.
2. Initialiser un projet.
3. Copier workflow.ts dans 
8n/workflows/.
4. Lancer 
8ncli push.
